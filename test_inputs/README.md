# Sample Inputs For Manual Testing

Use these files in the Streamlit app at `http://127.0.0.1:8501`.

Upload these required files:

- Activity JSON: `test_inputs/activity/activity_log.json`
- Attendance JSON: `test_inputs/attendance/attendance.json`

Optional files:

- Audio: `test_inputs/audio/sample_speech.wav`
- Homework PDF: `test_inputs/homework/homework_submission.pdf`
- Video: use your own `.mp4`, `.mov`, `.avi`, `.mkv`, or `.webm` file

Suggested form values:

- Student name: `Aarav Sharma`
- Session ID: `session_sample_01`

Then click **Generate report**.
