# Video sample

Upload any real class recording here when testing video analysis.

Supported formats in the Streamlit app:

- `.mp4`
- `.mov`
- `.avi`
- `.mkv`
- `.webm`

This sample pack does not include a generated video because this environment does not have a video encoder available. The app can still generate a report without video; the focus score will stay at `0` until you upload a real video file.
